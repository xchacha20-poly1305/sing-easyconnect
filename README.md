# sing-easyconnect

Part of easyconnect reverse engineering. The full implementation is digging.

This protocol is only a "fake TLS" protocol when `enc` == 1, only the authentication uses real TLS 1.2, the tunneled traffic only xor with a hard code key.

All the code is generated by LLM. Reverse engineering is by Grok 4.6, endpoint implemented by Claude Opus 5.
